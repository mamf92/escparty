# Long-Term Goals

These goals reflect the current product direction and should stay in sync with the README milestones.

## Milestones
- Summer 2026: single and multiplayer quiz runs reliably with live sync so all players receive questions and answers at the same time.
- Fall 2026: hosts for multiplayer quizzes and single-player quiz selection by country, difficulty, and ESC-only sets, including local content tied to country selection.
- Fall 2026: hosts can create custom quizzes by entering their own questions or selecting from existing question banks, with the same filters (country, difficulty, ESC).
- Winter 2026/2027: participating countries view with songs as they become available, sortable from most liked to least liked.
- Winter 2027: classic score sheets created by host with live group ratings in a shared room; hosts can pick categories (costume, staging, voice, show) or use presets.
- Spring 2027: post-event analysis highlights alignment and differences between participants (e.g., most aligned, biggest differences, opposites).

## Notes
